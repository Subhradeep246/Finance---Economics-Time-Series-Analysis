# Derived Features

This file documents the derived columns generated by `features.generate_features` and the demo script `feature_demo.py`.

| Column name pattern | Description | Notes |
|---|---|---|
| {base}_ret | Simple percent change: x_t / x_{t-1} - 1 | Standard discrete return; NaN for first row |
| {base}_logret | Log return: diff of log(x) | Useful for additive returns and modeling; NaN for first row or non-positive values |
| {base}_roll_mean_{w} | Rolling mean over window w | w is typically 5, 10, 20 in defaults; min_periods=1 is used in demo |
| {base}_roll_std_{w} | Rolling standard deviation over window w | Measures local volatility; min_periods=1 in demo |
| {base}_vol_20 | Volatility: std of returns over 20-period window | Computed on returns (pct_change) by default |
| {base}_ret_lag_k | Return lagged by k periods | Used as lag features for autoregressive models |
| {base}_diff_1 | First difference: x_t - x_{t-1} | Simple absolute change between consecutive observations |
| {base}_wdiff_1w | Calendar-aligned weekly difference: x_t - x_{t-1 week} | Uses pandas DateOffset(weeks=1) alignment; will be NaN if exact calendar match is missing (e.g., weekends) unless index is business-day aligned |
| {base}_mdiff_1m | Calendar-aligned monthly difference: x_t - x_{t-1 month} | Uses pandas DateOffset(months=1); may be NaN when the exact prior month date isn't present (holidays, month length)
| {base}_mdiff_3m | Calendar-aligned 3-month (quarterly) difference | Same caveats as monthly diffs; useful for quarter-over-quarter comparisons |
| {base}_mdiff_12m | Calendar-aligned 12-month (yearly) difference | Year-over-year comparison; useful for seasonal adjustments |

## Calendar-diff details
- The calendar-aligned diffs (weekly/monthly/quarterly/yearly) use pandas DateOffset to compute the prior timestamp. If your dataset's index is a business-day index or missing exact calendar dates (weekends/holidays), these diffs will be NaN for rows where there's no exact prior-timestamp match.
- If you prefer a nearest previous business-day fallback, consider implementing a small helper that, for each date, searches backwards up to N days for the nearest available index value.

## How to use
- Run `feature_demo.py` which calls `generate_features` and will create the derived columns for the detected price column.
- The demo saves the first 10 rows to `features_head10.csv` for easier inspection.
